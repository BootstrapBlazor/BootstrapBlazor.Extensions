# SvgEditor API 参考

此 skill 随 `BootstrapBlazor.SvgEditor` NuGet 包分发，参考文档从打包时的工程源码生成。

1. 阅读 [references/llms.txt](references/llms.txt)，定位当前包中的组件。
2. 阅读 [references/components/SvgEditor.txt](references/components/SvgEditor.txt)，确认参数、事件回调和公开方法的名称与签名。

优先读取当前项目实际还原版本的文档，不要选择全局缓存中的最高版本。参数与调用签名必须与文档一致，不要凭记忆编造 API。

文档仅分析当前工程源码，外部基类和 Razor `@code` 中的成员可能未收录。需要继承成员时，应查询项目实际引用版本的基类资料；资料不可用时说明缺失，不要猜测。

此 skill 为只读参考资料，不包含脚本。
